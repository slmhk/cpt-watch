# SOURCES — what works, what is blocked, how to search each source
(The research run may add or prune entries here as it learns; this file is meant to evolve.)

VERIFICATION STANDARD: a school is "verified" restricted or clear only by the school's own page (ISSS/OISS/announcement blog — e.g. UIUC's is blogs.illinois.edu/view/8569, not isss.illinois.edu) or the school's student newspaper. Aggregator/agency/coaching sites (collegedunia, shiksha, yocket, leverageedu, education-agency zhihu posts) are NOT verification — keep the lead a lead and cite them only as the pointer. When promoting, read the official text for the honour/cancel posture so the school lands in the right tier first time.

LEADING INDICATORS (students report DSO emails days before official pages change; every hit is a LEAD to verify, never a confirmation):
- 1point3acres.com (一亩三分地, the main Chinese-language forum for international students in the US). Tag-index direct fetch (https://www.1point3acres.com/bbs/tag/cpt-76-1.html) is unreliable (PROVENANCE_REQUIRED timeouts since 09-08) — at most one retry per run. Two ways that work: (1) WebSearch allowed_domains ["1point3acres.com"] with Chinese terms: CPT 暂停 (paused) / 取消 (cancelled) / 学校 (school) / DSO 邮件 (DSO email) / 实习 (internship) / SEVP 新规 (new rule) — surfaces thread titles/URLs; (2) an individual thread fetch (e.g. thread-1186153-1-1.html) works once it has search provenance. Thread 1186153 (Aug 14–25) surfaced Berkeley and UCSD before official notices and named UIUC; as of 09-10 nothing newer.
- zhihu.com — search snippets only (fetch is robots-blocked). Mostly education-agency posts; useful for headlines that name schools. Verify anything it names.
- linkedin.com — search snippets only, noisy; immigration attorneys and DSOs post there. Low yield; occasional.
